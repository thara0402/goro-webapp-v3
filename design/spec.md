# 孤独のグルメ巡礼サイト 機能仕様書

## 目的

「孤独のグルメ」に登場した店舗を探し、放送内容を振り返りながら、実際に店舗を訪問するための情報を得られる巡礼サイト。

## アプリでユーザーができること

### 1. 放送シーズン・話から登場店を探す

- ホーム画面のシーズンドロップダウンで Season 1〜N を切り替える。
- 選択したシーズンに登場した店舗の一覧を表示。
- 一覧には各話の話数、エピソード題名、店舗名を表示。
- 複数話に登場する店舗、および複数店舗が登場する話に対応。
- 各行の「詳細」ボタンから店舗詳細ページへ遷移可能。

### 2. 店舗の詳細情報を確認する

店舗詳細ページで、次の情報を確認できます。

**表示情報**:
- 登場シーズン（Season）と話数（Episode）
- エピソード題名（Title）
- 店舗名（Restaurant）
- 最寄り駅などのアクセス情報（Access）
- 電話番号（PhoneNumber）
- 住所（Address）
- 営業状態（Status: 営業中 / 閉店 / 一時閉店 / 未確認）
- 地図表示（Google Maps、座標情報がある場合のみ表示）

詳細ページから検索元ページへ戻ることが可能（ブラウザの戻るボタン、または遷移元リンク）。

### 3. 任意の場所を起点に近くの店を探す

- 「近くの店舗を探す」ページで、駅名・地名・施設名をテキスト入力。
- 入力した場所を Google Geocoding API で座標（緯度・経度）に変換。
- 座標を基点として、最寄りの登場店舗を検索。
- 検索結果を距離の近い順に表示（最大 10 件）。
- 検索結果のテーブルには Season、Episode、Title、Restaurant を表示。
- 各検索結果から詳細ページへ「詳細」ボタンで遷移可能。
- 検索結果ページから「近くの店舗を探す」ページへ戻ることが可能。

## 実装機能一覧

| 機能 | 説明 | 実装状態 |
| --- | --- | --- |
| **シーズンフィルタ** | Season 1-N のドロップダウン選択で店舗一覧をフィルタ | ✅ 実装済 |
| **店舗一覧表示** | 選択シーズンの店舗をテーブルで表示（話数、題名、店名） | ✅ 実装済 |
| **店舗詳細表示** | Season、Episode、Title、Restaurant、Access、Phone、Address、Status を表示 | ✅ 実装済 |
| **地図表示** | Google Maps API で店舗位置を地図上に表示 | ✅ 実装済（座標あり時） |
| **住所→座標変換** | Google Geocoding API で入力地名を座標に変換 | ✅ 実装済 |
| **近隣店舗検索** | Cosmos DB ST_DISTANCE 空間クエリで最寄り店舗を距離順取得 | ✅ 実装済 |
| **検索結果表示** | 最寄り店舗 TOP 10 をテーブルで表示 | ✅ 実装済 |
| **ページ遷移** | シーズン一覧 ↔ 詳細ページ ↔ 近くの店検索ページ間の移動 | ✅ 実装済 |

## 画面一覧

| 画面名 | 主要コンポーネント | 用途 |
| --- | --- | --- |
| **ホーム（Home/Index）** | シーズンドロップダウン、店舗テーブル | 放送シーズン・話から店を探す |
| **店舗詳細（Home/Details）** | 店舗情報カード、Google Maps 地図 | 訪問予定の店の詳細情報確認 |
| **近くの店舗を探す（Navi/Index）** | 検索フォーム、結果テーブル | 現在地または指定場所の近隣店を検索 |

初期リリースでは、以下を実装対象とします。

1. ✅ シーズン・話ごとの店舗一覧表示
2. ✅ 店舗詳細情報と地図表示
3. ✅ 場所を指定した近隣店舗検索
4. ✅ Google Maps 統合
5. ✅ 各ページ間のナビゲーション

## 画面デザイン

### デザインコンセプト

Microsoft 365 や Azure Portal のような、シンプルでモダンな業務 Web アプリケーションをイメージする。派手な装飾や過度に個性的な表現は避け、店舗情報を探しやすく、読みやすく、操作しやすい画面を目指す。

次の方針を重視する。

- シンプルで清潔感がある
- 情報が整理されており、必要な情報をすぐに確認できる
- 文字や項目の視認性が高い
- 初めて利用するユーザーでも操作しやすい
- PC、タブレット、スマートフォンで利用できる
- 商用 Web アプリケーションとして画面全体に統一感がある
- コンテンツを主役とし、目的のない装飾やアニメーションを使用しない

### Bootstrap の利用方針

既存の Bootstrap を画面デザインの基本フレームワークとして最大限活用する。Grid、Container、Row、Column を適切に使用し、Button、Card、Table、Form、Alert、Badge、Navbar などの標準コンポーネントを優先して利用する。また、spacing、display、flex、text、color などのユーティリティクラスを積極的に活用する。
